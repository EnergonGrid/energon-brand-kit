ENERGON — Guardian Chronicle
This repository contains the public Guardian Chronicle for the ENERGON protocol.
The Chronicle is the narrative and historical record of Energon. It documents protocol principles, identity rules, Guardian observations, and the growth of the Grid through verifiable on-chain events.
It does not execute protocol logic.It does not grant protocol access.It does not imply rewards.It does not override immutable protocol behavior.

Purpose
The Guardian Chronicle exists to be read.
It documents:
* The Rule of One
* Guardian identity constraints
* The relationship between EnergonCubes and the Grid
* Significant protocol milestones
* Verified Guardian observations
All protocol enforcement occurs on-chain through immutable smart contracts.

Canon
Protocol behavior is governed exclusively by:
* The ENERGON Whitepaper
* The Energon Management Protocol (EMP)
* Immutable deployed smart contracts
If documentation and deployed contracts ever differ, the deployed contracts are the source of truth.
The Chronicle reflects canon.It does not define it.
