# Logo Usage

Use the **Primary Logo** whenever possible.

The **SVG** version should be used for websites, documentation, presentations, and print.

The **PNG** versions should be used for wallets, block explorers, social media, applications, and any environment that does not support SVG.

Do **not**:

- Modify the logo colors
- Stretch or distort the logo
- Rotate the logo
- Change the typography
- Add effects or overlays
- Combine the logo with other graphics in a way that implies official endorsement

Maintain adequate clear space around the logo whenever possible.

# Brand Principles

The Energon brand represents:

- Permanence
- Transparency
- Determinism
- Observable protocol state
- Verifiable on-chain identity

Avoid messaging that implies:

- Guaranteed profits
- Investment returns
- Yield generation
- Governance control over immutable protocol rules

Energon is an immutable blockchain protocol whose behavior is defined by deployed smart contracts and observable on-chain state.
